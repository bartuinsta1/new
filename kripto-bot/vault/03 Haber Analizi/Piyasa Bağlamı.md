# Piyasa Bağlamı (piyasa bloğu, %20)

Altcoinler BTC'den bağımsız değildir. BTC düşerken alınan altcoin genelde daha çok düşer.

| Etken | Artı | Eksi |
|---|---|---|
| BTC 24s değişim | > +%2 | < −%2 · **−%6 altı veto** |
| BTC trendi | EMA50 üstü | EMA50 altı |
| Korku/Açgözlülük | ≤20 aşırı korku (tersine fırsat), 55+ iyimser | ≥80 aşırı açgözlülük (tepe riski) |
| Likidite (24s hacim) | 50M $+ | 3M $ altı |
| Spread | ≤ %0.6 | > %0.6 **veto** |
| 24s pompa | | +%40'tan fazla: tepeye binme riski |
